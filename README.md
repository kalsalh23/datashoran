# أطباء وصيدليات مدينة سوران

منصة بسيطة (واجهة واحدة) لجمع بيانات الأطباء والصيدليات في مدينة سوران وحفظها في قاعدة بيانات Supabase لاستخدامها لاحقاً.

## الواجهات

- **واجهة الأطباء:** الاسم، الاختصاص، الموقع، أيام الدوام، أوقات الدوام، يوم العطلة، رقم التواصل.
- **واجهة الصيدليات:** اسم الصيدلية، اسم الدكتور، الموقع، أوقات الدوام.

بعد تعبئة الحقول يضغط المستخدم زر **«إرسال البيانات»** فتُحفظ البيانات مباشرة في Supabase.

## التقنيات

- HTML + CSS + JavaScript بدون أي إطار عمل (صفحة واحدة، ثنائية اللغة العربية RTL).
- الاتصال بقاعدة البيانات عبر Supabase REST API مباشرة من المتصفح.

## قاعدة البيانات

جدولان: `doctors` و `pharmacies`. سكربت الإنشاء في [sql/schema.sql](sql/schema.sql) (يُنفَّذ من Supabase SQL Editor).

الحماية مفعّلة بسياسة RLS تسمح للزوار **بالإضافة فقط (INSERT)**، ولا تسمح بالقراءة للعامة — عرض البيانات يتم من لوحة تحكم Supabase (Table Editor).
